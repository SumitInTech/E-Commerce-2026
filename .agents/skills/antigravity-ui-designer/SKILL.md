# Antigravity Ultra-Creative Luxury UI Designer Skill

When designing or modifying frontend components for the E-Commerce platform:
1. **Never build basic, generic, or flat MVP interfaces.**
2. **Luxury Cyber-Streetwear Aesthetic**:
   - Deep obsidian backgrounds (`#070709`, `#0a0a0f`) layered with floating frosted-glass surfaces (`backdrop-filter: blur(24px)`).
   - Accents of Liquid Cyber Cyan (`#00f0ff`), Champagne Metallic Gold (`#d4af37`), and Neon Magenta (`#ff007f`).
3. **Interactive 3D Card Physics**:
   - Product cards and hero cards must feature smooth mouse-tracking tilt effects, interactive light-sheen reflections, and elevated depth hierarchy.
4. **Holographic Badges & HUD Elements**:
   - AI tags, fit status badges, and department selectors must feature cybernetic borders, pulsing micro-dots, and animated gradient borders.
5. **Living Micro-Animations**:
   - Smooth buttery cubic-bezier transitions (`cubic-bezier(0.16, 1, 0.3, 1)`).
   - Dynamic glow pulses, holographic scanning lasers in the AI Fit Lab, and responsive quick-action pill buttons.
